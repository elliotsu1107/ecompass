运营看板 导入数据

1. 运营人员

先建立运营人员，类目需要指定负责的运营。

2. 店铺

店铺用于导入报表和统计店铺目标。

3. 类目

类目需要绑定运营，商品报表和推广报表按商品 ID 归类。

4. 商品

商品报表和推广报表通过商品 ID 匹配这里的类目与运营，请先建立商品清单。

5. 月度目标

店铺目标和类目目标按店铺分别设置，运营目标是两家店铺合计。

清空全部业务数据

操作前系统会自动备份数据库。管理员资料、数据库结构和备份文件不会删除。

删除范围：

  • 店铺、类目、运营人员
  • 产品资料
  • 店铺、商品和推广日报
  • 店铺、类目和运营目标
  • 导入记录和字段映射
